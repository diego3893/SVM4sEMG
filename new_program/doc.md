# 生机电の小实验

1. 实验目的：使用svm做二分类，预测当前的肌电信号是对应手的舒展还是紧握动作
2. 数据分析
   - 根据资料（哈基米提供），正常肌电信号电压分布为$\pm 5mV$，我们的数据峰值集中在$\pm 1mV$中，属于正常范围
   - 静息电位在0上下浮动，我们的数据也符合
3. 数据预处理
   - 考虑到数据采集时的干扰信号，我们需要滤波来去除噪声
   - 手部采集时的低频震动，考虑使用20-200Hz的带通滤波，只允许20-200Hz的数据通过
   - 交流电为50Hz，会带来一个必然存在的干扰，因此用48-52Hz的陷波滤波将48-52Hz的信号除去
4. 数据处理
   - 从csv中读取包含**EMG**字段的列，即第2列和第6列
   - 对这些数据切片，去除前200ms的数据，避免刚开始采集的不稳定性带来的负面作用
   - 对数据做滤波（预处理）
   - 对数据做窗口滑动特征采集，每个窗口计算一次特征；且保证窗口有相当程度的重叠，以便于让离散的窗口有连续的上下文
     - 窗口决定了特征计算需要的**信息量**，而步长决定了特征输出的**连续性和灵敏度**
   - 对每个窗口计算下列特征：
     1. 平均绝对值，反应窗口内肌肉收缩的平均力度（波的高度）
     2. 平均绝对值斜率，对比窗口前后半段的能量差异，捕捉发力/放松的趋势（将窗口前后半段分别计算mav，作差）
     3. 过零率，信号过0点的次数，反应了放电频率
     4. 波形长度，累计相邻采样点之间的变化梯度，是反应信号幅度和频率综合复杂度（幅度和频率都影响波形长度，波形长度为波的曲线拉直后的线段长）
5. 标签分类方法
   - 使用VSCode插件将csv可视化，便于分类
     - x为`rows`，即数据点；y为第二列和第六列数据（即包含**EMG**字段的列）
   - 观察图像，直观地发现一部分的数据的峰值集中在前半段，为舒展；另一部分的峰值集中在后半段，为握紧
   - 将两类数据分别放在`label0`和`label1`两个子文件夹中

5. 支持向量机训练
   - 这是一个用来做二分类的算法
   - 将得到数据打好标签，按照4:1分为训练集和测试集
   - 先用训练集训练svm，后用测试集评估其性能和泛用性
   - 尝试交叉验证训练，并用训练结果最好的一组作为最终结果
     - 参数含义如下：
       - C：惩罚系数，对错误分类数据的容忍度
       - gamma：单个数据样本可以影响多远的范围
       - kernel：使用rbf核，处理线性不可分数据
     - `GridSearchCV(svm.SVC(), param_grid, cv=5, n_jobs=-1)`
       - `svm.SVC()`：传入一个空白svm
       - `param_grid`：手动定义的超参集
       - `cv=5`：5折交叉验证，每次把训练集分为5份，4份训练1份测试，求平均分来标识模型的好坏
       - `n_jobs=-1`：加速并行计算
     - 最后调用`fit()`让svm穷举超参，得出最优解。总共$4\times 4\times 5=80$次枚举
6. 主函数逻辑
   - 从`./data`中读取数据
   - 按照子文件夹名称来打标签，所有`./data/label0`中的csv标为0，`./data/label1`中的标为1
   - 打完标签后，将训练集和测试集的X做归一化，避免不同特征数量级差异导致的误差
     - 为什么要归一化？
       - mav可能在$10^{-5}\sim 10^{-3}$的数量级左右，而zc的数量级可能是几十上百
       - rbf核靠计算欧氏距离来分类，这种数量级差异会让svm忽略某些小数量级的特征
     - 如何归一化？
       - `StandardScaler()`：零均值归一化，将数据统一为均值为0，方差为1的分布
   - 训练svm并评估性能（准确度）
